# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

# Frank Omini | Developer Portfolio

A modern, responsive personal developer portfolio built with **React.js, JavaScript, HTML5, and CSS3**. The portfolio showcases my technical skills, selected software development projects, certifications, and professional background, while providing an accessible way for recruiters, collaborators, and potential clients to connect with me.

## 🚀 Overview

The Franklin Portfolio is designed to establish my professional online presence as a Full-Stack Web Developer. It features a clean, modern interface with a dark-themed design, responsive layouts, and reusable React components.

The portfolio highlights my interest in building practical, user-friendly web applications and developing solutions across frontend and backend technologies.

## ✨ Key Features

- **Responsive Navigation:** Simple navigation with links to different sections of the portfolio.
- **Hero Section:** Professional introduction, developer role, and quick access to projects and GitHub.
- **About Me:** Overview of my development interests and technical focus.
- **Technical Skills:** Organized display of programming languages, frameworks, and development tools.
- **Project Showcase:** Reusable project cards displaying project descriptions, technologies, screenshots, and repository links.
- **Certifications:** Dedicated section for professional certifications and credentials.
- **Contact Section:** Direct links for professional enquiries and collaboration opportunities.
- **Modern UI:** Dark-themed interface with smooth hover effects, card transitions, and responsive layouts.

## ⚙️ Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Ensure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (Node Package Manager)
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Ubifranklin/franklin-portfolio.git
```

**2. Navigate into the project directory**

```bash
cd franklin-portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

*Note: The development commands above assume the project uses Vite.*
